# Changelog

Pending changes live in `entries/`. Released changes live in the top-level
[`CHANGELOG.md`](../CHANGELOG.md); consumed fragments are deleted.

Use [qlog](https://github.com/qbaylogic/qlog), available in `nix develop`, to
manage entries. Each entry should link to its relevant PR.

Follow [the release guide](../docs/releasing.md) to consolidate notes locally
before pushing. CI publishes the prepared release section from `CHANGELOG.md`.
