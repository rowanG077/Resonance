# Haste

An example spell mod. Haste is a support spell for Raine. It targets one party
member and speeds up everything they do by 20% for thirty seconds: attacks and
artes play and resolve faster, spells chant, release and recover faster, and
they walk and run faster. Raine learns it at level 12 and it costs 14 TP.

While the spell takes hold, a brass clock appears over the recipient. Its red
second hand and the two-wheel counter beneath it advance together, one step per
tick, starting at four ticks a second and winding up to thirty before the clock
fades. Each step plays the menu's navigation tick.

Enable it by copying or linking this directory into `local/mods`, for example
as `local/mods/000250-haste`, or pass `--mod mods/haste`. The spell has no
number; the game assigns one at startup and saves record it by name. A party
whose Raine is already level 12 or above learns it at her next level-up.

## Files

| File | Purpose |
| --- | --- |
| `mod.json` | Name and the cooked layout this mod targets. |
| `game/techniques/techniques/haste/rules.json` | The ordinary casting rules: TP, cast time, target kind, chant glow, learning level, and the `spell` document that releases it. |
| `game/techniques/techniques/haste/text.json` | Name and menu caption. |
| `game/techniques/learning/raine/haste/` | Registers the spell in Raine's learning list. |
| `battle/spells/haste/spell.json` | The release: one `haste` pulse of 20% for 1800 updates on the target, shown with program 0 of the spell's own effect bank, and Sharpness's voice lines. |
| `battle/spells/haste/effects.json` | The clock: four particle templates and one program that re-spawns the hand and the counter digits at each tick. |
| `battle/spells/haste/textures/clock.ktx2` | The clock face, hand, counter plate and digit wheels. Original artwork. |

## Changing it

`percent` and `duration` in `spell.json` set how strong Haste is and how long it
lasts. A spell holds its caster's spell slot for its `duration`; while it does,
the caster's next chant does not count down, so keep it close to the length of
the clock.

The artwork and the effect program are generated by `tools/haste_clock.py`.
Edit `TICKS` there to change how the clock winds up, or the drawing functions
to change how it looks, then run from the repository root:

```sh
python3 tools/haste_clock.py
resonance-import texture --input local/haste-clock.png \
  --output mods/haste/battle/spells/haste/textures/clock.ktx2
```

`effects.json` can also be edited by hand; it is the ordinary battle effect
format.

## How Haste works

Haste is a timed battle condition with a percentage. An actor under it is owed
one extra action tick every `100 / percent` updates, taken in the same update,
so a 20% Haste runs six ticks of an attack, a chant or a recovery in five
updates. Its animation plays 20% faster to match, and its walk and run speeds
rise by the same percentage. Hit-stop, item use and reactions to being hit are
not sped up. A new application replaces the current one, and curing every
ailment at once removes it, as it does the other timed boosts.
